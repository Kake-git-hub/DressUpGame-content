# DressUpGame-content

[きせかえゲーム](https://github.com/Kake-git-hub/DressUpGame) が読み込む素材（ドール・服・背景）です。
GitHub Pages で配信され、アプリは `manifest.json` を読んで画像を取得します。

- `manifest.json` … 素材の一覧（ドール、カテゴリ、服、背景、画像の位置情報）
- `files/` … 画像ファイル。名前は内容のハッシュなので、手で編集・改名しないでください

このリポジトリの中身は、アプリ側のリポジトリにあるツールが書き出します。手で編集する場所ではありません。
